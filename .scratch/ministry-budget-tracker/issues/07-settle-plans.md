# 07: Settle plans and retain optional remainders

**What to build:** The owner turns a plan into an actual purchase, edits final details, and optionally keeps a remainder planned.

**Blocked by:** 05: Classify purchases with splits and initiatives, 06: Plan, edit, commit, and cancel purchases.

**Status:** draft — pending testing-seam and ticket-breakdown review

- [ ] Settlement form prefills editable actual amount, date, description, and allocations.
- [ ] Default settlement closes the plan and counts only the actual spending.
- [ ] Optional remainder is explicitly reviewed and remains planned with an internal relationship to the actual purchase.
- [ ] Split actual and remainder allocations each reconcile; original estimates remain visible.
- [ ] Repeated requests and concurrent settlement cannot double-count or settle the same remaining amount twice.
- [ ] Demonstrate both settlement paths on phone and desktop with correct balances.
