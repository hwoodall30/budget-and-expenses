# Planning review

The product scope is confirmed. These documents are local drafts for the review required by to-spec and to-tickets; no external issues were published and no implementation began.

- [Specification](spec.md)
- Proposed primary testing seam: authenticated application operations against a disposable database, shared by web and MCP; a few browser journeys cover interaction and deployment boundaries.
- Review questions: Does this seam fit? Is ticket granularity appropriate? Do blockers reflect genuine prerequisites? Should any slices merge or split?
- On approval, change draft status to ready-for-agent. That status means actionable once listed blockers are complete, not that every ticket can start at once.
- Ticket 01 is the human usability gate; ticket 13 is core pilot completion. Ticket 14 is secondary. Ticket 15 is an optional research task, not an implementation slice and not a pilot blocker.
- Implementation recommendations to review include cross-year refund accounting, refund caps, backup-origin compatibility, and explicit deleted-record conflict handling.
